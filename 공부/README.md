## 공부 순서
지문마다 아래 단계를 차례로 진행합니다. 문법을 몰라도 메뉴의 "유형별"에서 개념부터 볼 수 있어요.
0. 수업: 한 문장씩 끊어 읽기 → 해석 → 어법 설명 → 확인 문제 (다 맞혀야 다음 문장)
1. 읽기: 본문 전체 훑어보기, 해석 가리고 복습
2. 고르기: 어법·어휘 [A / B] 중 하나 고르기
3. 쓰기: 고르던 자리에 정답 직접 쓰기
4. 배열: 우리말을 보고 어구 순서 맞추기
5. 실전: 직전보강 서술형 워크시트
6. 영작: 핵심 문장을 통째로 쓰기

틀린 문항은 오답노트에 모입니다.

## 직전보강 공부·시험 (첫 화면 주황 타일)
모의고사 팩에서 직전보강 문제만 따로 공부하고 시험 봅니다.
- 범위 고르기: 지문 번호를 눌러 넣고 빼기
- 공부하기: 문제 + 정답 + 해설을 보면서 답을 직접 써 보고 채점. 위의 "정답 보임/가림" 버튼으로 정답을 가리고 먼저 쓸 수 있음. "알아요 / 헷갈려요" 표시 → "헷갈리는 것만"으로 다시 보기
- 시험 보기: 채점 없이 끝까지 풀고 제출 (순서 섞기, 제한 시간 10~60분 선택)
- 결과: 점수, 지문별·유형별 정답률, 틀린 문제 해설(내 답 vs 정답), 틀린 것만 다시 시험. 틀린 문항은 오답노트에도 들어감

## 새 자료 추가하기 (study-pack@1 형식)
새 교재나 워크북도 이 형식의 JSON으로 만들어 두 가지 방법으로 넣을 수 있습니다.
- `packs/`에 추가하고 `packs/index.json`에 등록
- 앱의 "자료 → 자료 가져오기"로 바로 불러오기

들어 있는 항목에 맞춰 단계가 자동으로 생깁니다.
- `lines`가 있으면 읽기·고르기·쓰기·배열
- `sheet`가 있으면 실전
- `write`가 있으면 영작

```json
{
  "schema": "study-pack@1",
  "id": "bisang-eng2-l3",
  "title": "비상 영어II 3과", "short": "비상 3과", "scope": "본문 ❶~❽",
  "sources": ["출처 설명"],
  "stages": {"sheet": "직전보강 실전"},
  "units": [{
    "id": "r1", "title": "본문 ❶", "topic": "", "topicKo": "",
    "lines": [{
      "en": "Everybody {0} a hobby.", "ko": "누구나 취미가 있다.",
      "c": [{"o": ["has", "have"], "a": 0, "why": "수일치 · everybody는 단수"}],
      "notes": [{"t": "수일치", "p": "단수주어+단수동사", "b": "설명"}]
    }],
    "sheet": {"given": "", "pre": "", "s": [{"k": "❶", "t": "워크시트 지문 문장"}],
              "q": [{"n": 1, "ref": "❶", "type": "어법", "cells": ["어법상 틀린 부분을 1군데 찾아 고치시오."], "a": "x → y"}]},
    "write": [{"ko": "우리말", "en": "영어 정답", "cond": "조건(선택)", "kw": "핵심 단어(선택)"}]
  }]
}
```

### 필드 규칙
- **`id`:** 영문, 숫자, `-_.`만 씁니다. 진행 기록이 이 id로 저장되므로 한 번 정하면 바꾸지 않습니다.
- **`lines[].en`:** 고르는 자리를 `{0}`, `{1}`처럼 표시합니다. `c[i].o`는 선택지 목록, `c[i].a`는 정답 번호(0부터)입니다.
- **`sheet.q[].type`:** `어법`, `어휘`, `혼합`, `주제`, `제목`, `삽입`, `연결`, `빈칸`, `서술`, `해석` 등을 씁니다.
  - 정답(`a`) 쓰는 법은 고치기 문제면 `① x → y ② a → b`, 삽입 문제면 `Between ❺ and ❻`입니다.
  - 정답이 여러 개일 때:
    - 같은 답의 다른 형태는 `playing(play)`처럼 괄호에 씁니다.
    - 완전히 다른 답은 `which or 생략`처럼 `or`로 잇습니다.
- **진행 기록:** 브라우저(계정 동기화)에 팩 id별로 저장됩니다. 키는 `c|단원|문장`(고르기), `r|…`(쓰기), `o|…`(배열), `s|단원|문항`(실전), `w|단원|번호`(영작)입니다.
