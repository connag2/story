# 스토리 공부방 📚

과목별·단원별로 문제를 풀고 바로 채점하는 공부용 웹앱입니다. 빌드 없이 `index.html`만 열면 돼요.

디자인과 흐름(과목 칩, 타일 메뉴, 진행 점이 있는 단원 카드, 오답노트)은 `공부/`의 **고2 영어 공부장**을 따랐고, 영어Ⅱ는 그 앱을 그대로 엽니다.

## 기능

- **공부법 · 개념 먼저:** 과목마다 「📘 공부법」(시험 구성 · 공부 순서 · 자주 하는 실수), 단원을 처음 열면 「개념」 단계(정의 · 공식 · 예시 · 함정)가 먼저 나와요. 내용은 `data/guides.js`.
- **영어 공부장처럼 보기:** 단원마다 ① 지문 읽기(지문 있는 단원) ② 한 문제씩 ③ 전체 보기 ④ 틀린 문제 단계. 한 문제씩 볼 때는 아래 막대(이전 · 진행 점 · 다음), 키보드 ←/→, 넓은 화면에서는 지문이 왼쪽에 붙어 있어요.
- **🐍 프로그래밍 집중:** 시험범위 정리표(리스트 · 딕셔너리 · 연산자 · 조건/반복 · 함수 · 재귀)대로 5~10단원 93문제 추가. **서술형 실전**(연습문제의 모스 부호 · 로봇 명령 + 비슷한 문제 4개)은 앱 안에서 코드를 직접 쓰고 ▶ 실행 · ✅ 자동 채점(여러 입력을 한꺼번에 검사, 나와야 할 출력과 내 출력 비교, 오류를 쉬운 말로 설명)해요. 「🐍 파이썬 연습장」(#/py)에서 자유롭게 실행. 실행기는 Skulpt(vendor/skulpt, 인터넷 없이 동작)이고, 모든 실행 결과 답은 실제로 돌려서 확인했어요.
- **📝 풀이 과정:** 모든 수학 문제와 해설이 없던 문제에 단계별 풀이가 있어요. 틀리면 펼쳐서, 맞으면 접어서 보여 줘요(시험 결과·오답노트에도). 내용은 `data/solutions-*.js` — 문제 목록은 `node scripts/list-items.mjs math 1` 로 볼 수 있어요.
- **✏️ 필기 (펜 · 펜 태블릿 · 마우스 · 손가락):**
  - 오른쪽 아래 ✏️(또는 W 키)를 누르면 **화면 전체**(문제 · 지문 옆 창 · 해설까지)가 종이가 돼요. 쓴 것은 **문제마다 저절로 저장**되고, 「다음」으로 넘기면 필기 모드는 그대로 그 문제의 종이로 바뀌어요.
  - 손가락으로 끌면 **원래 스크롤 그대로**(관성 · 두 손가락 확대) 넘어가고, 쓴 필기는 글씨에 붙어서 같이 움직여요. 톡 누르면 보기·버튼이 눌려요. 펜으로 쓰는 동안 닿은 손바닥은 무시해요. ⋯ 에서 손가락 모드(자동 · 손가락으로 쓰기 · 넘기기 · 손바닥 막기)를 바꿔요. 👆(T) 「누르기」를 고르면 필기를 잠깐 멈춰요. Esc 로 끄기.
  - 「📓 연습장」은 문제마다 넓은 모눈 종이, 홈·과목 화면의 「📓 필기장」은 과목마다 여러 쪽(줄 노트/모눈/무지, 늘리기, PNG 저장).
  - 펜(애플펜슬 · S펜 · 와콤 등)은 누르는 힘에 따라 굵기가 바뀌어요. 펜을 한 번 쓰면 손가락은 넘기기·누르기만 해요(손바닥 무시). 펜 지우개 끝이나 옆 버튼을 누르고 쓰면 지우개.
  - 펜 · 형광펜 · 지우개 · 누르기. 막대의 ● 를 누르면 **색 고르기**(12색 · 🎨 아무 색이나 · 최근 색) · **굵기 슬라이더** · 형광펜 **진하기**. 펜과 형광펜은 색·굵기를 따로 기억(형광펜 기본 노랑). 지우개는 **획 통째로 / 닿은 부분만** · 크기 조절. Ctrl+Z / Ctrl+Y, 단축키 P · H · E · T, 막대 위/아래(⋯). 필기는 이 기기에 저장돼요.
- **⚙️ 설정 (오른쪽 위):** 🌙 어두운 화면(기기 따라 자동도), 글자 크기 4단계, 하루 목표(홈에 진행 막대). 로그인하면 다른 기기와 맞춰져요.
- **⏱ 공부 타이머:** 25/40/50분 집중 → 5/10분 쉬기. 끝나면 소리·진동·알림, 홈에 「오늘 집중 N분」.
- **⭐ 별표:** 문제 오른쪽 위 ☆(S 키) → 홈의 「⭐ 별표 문제」에 모여요.
- **🔍 검색 (/ 키):** 문제 · 지문 · 풀이 · 개념 · 공부법에서 찾고, 누르면 그 문제로 바로 가요.
- **⌨️ 단축키:** ←/→ 이동, 1~5 보기 고르기, Enter 다음 문제, 댓글은 Ctrl+Enter 로 보내기.
- **📖 영어 본문 해설 (`#/eng`):** 영어 공부장의 교과서 · 모의고사 지문 50개(344문장)마다 🧭 한눈에 보기(주제 · 요지 · 글의 흐름 · 시험 포인트)와 문장별 **끊어 읽기 직독직해**, 해석(보이기 / 눌러서 보기 / 가리기), 단어, 어법 포인트(고르기 정답과 이유). 단어를 누르면 뜻, 🔊 로 문장·전체 읽어 주기(빠르기 조절), 「다 읽음」 표시. **읽기 막대**(▲▼ · 스페이스바)로 한 문장씩 집중하고, **▶ 자동 읽기**는 소리와 함께(읽는 단어를 노란색으로 따라감) 또는 조용히(읽는 속도에 맞춰) 알아서 다음 문장으로 내려가요. **🎙 성우**: AI 성우(코랄 · 노바 · 시머 · 마린 · 발라드 · 세이지 · 시더 · 애쉬 — 자연스러운 최신 음성) 또는 📱 기기 목소리(무료, 엣지·크롬의 Natural 같은 최신 음성을 먼저 골라요). **🎀 목소리**: 귀엽게(살짝 밝은 톤 · 자연스러운 목소리 먼저, 효과음 목소리는 뺌) / 보통 / 차분하게, 영어·한국어 목소리 직접 고르기, **영어만 · 영어 → 한국어 · 한국어만** 읽기(막대의 🇺🇸→🇰🇷 버튼). 끊어 읽기 덩어리를 누르면 영어와 뜻을, 해석 옆 🔊 는 한국어를 읽어 줘요. **⚠️ 꼭 볼 문장**: ⭐ 핵심 문장(주제문·결론) · ↪ 흐름이 바뀌는 문장(However·Instead 등 연결어는 보라색) · ✏️ 어법 고르기 자리(주황 밑줄) · 🧩 긴 문장을 표시하고, 그 문장만 모아 볼 수도 있어요. 영어 공부장 화면 오른쪽 아래 「📖 본문 해설」 또는 홈 타일로 들어가요. 해설은 `data/english-notes-*.js` (`node scripts/eng-lines.mjs <팩id>` 로 문장 보기, `node scripts/check-eng-notes.mjs` 로 점검).
- **바로 채점:** 답을 입력하면 바로 채점해요. `1/4`·`0.25`, `루트6`, `무한대`처럼 다르게 써도 맞게 처리해요. 서술형은 정답을 보고 스스로 ⭕/❌.
- **시험 보기:** 과목 화면의 「시험 보기」에서 단원·문제 수·시간 제한을 골라 실전처럼 풀고, 제출하면 점수·단원별 정답률·틀린 문제 해설이 나와요. "틀린 것만 다시 시험"도 돼요.
- **오답노트:** 전체/과목별로 틀린 문제만 모아 다시 풀어요.
- **오늘 화면:** 시험 D-day(날짜를 누르면 설정), 오늘 푼 문제 수, 연속 공부 일수, 이어서 풀기.
- **로그인·동기화:** 이름+비밀번호로 로그인하면 휴대폰·컴퓨터 기록이 자동으로 맞춰져요. **영어 공부장 기록도 같이** 맞춰져요. (Vercel 배포에서 동작)
  - 가입할 때 **복구 코드**를 한 번 받아요. 비밀번호를 잊으면 로그인 창의 「비밀번호를 잊었어요」에서 복구 코드로 다시 정해요.
  - 계정 창(오른쪽 위 이름)에서 비밀번호 바꾸기 · 복구 코드 새로 받기 · 다른 기기 모두 로그아웃 · 계정 삭제를 할 수 있어요.
- **💬 피드백 게시판 · 댓글:** 공부법 페이지와 단원 「개념」 아래, 그리고 홈의 「💬 피드백 게시판」에서 💬 의견 · 💡 나만의 공부법 · 🙋 추가 요청 · 🐞 오류 신고를 남기고 👍 할 수 있어요(로그인 필요, 모두 함께 봄).

  - **답글:** 글마다 「답글」로 한 단계 답글을 달아요. 답글이 있는 글을 지우면 "삭제된 댓글"로 남아요.

  - **🚫 차단:** 차단한 사람의 글은 내 화면에서 "차단한 사람의 글이에요"로 접혀요. 차단 목록은 내 기록과 함께 동기화돼요.
- **🪙 포인트:** 문제를 **처음 맞힐 때마다 1포인트**(다시 풀거나 기록을 지워도 늘거나 줄지 않아요). 서버가 계산해서 오른쪽 위에 보여 줘요.

- **앱처럼 설치 + 자동 업데이트:** Vercel 주소를 휴대폰에서 열고 "홈 화면에 추가"하면 앱처럼 열려요. 인터넷이 되면 열 때마다 최신 내용을 받아 오고, 안 되면 저장해 둔 것으로 열려요.

## 저장소: Upstash Redis (권장)

Vercel Blob 무료 한도는 금방 차서(한도를 넘으면 저장소가 멈춰 로그인이 안 돼요) **Upstash Redis** 를 먼저 써요.
1. Vercel 프로젝트 → **Storage → Create Database → Upstash (Redis)** → 무료(Free) 플랜 → 이 프로젝트에 **Connect**.
   (`KV_REST_API_URL`, `KV_REST_API_TOKEN` 이 자동으로 생겨요. `UPSTASH_REDIS_REST_URL/TOKEN` 이름도 돼요.)
2. 다시 배포하면 자동으로 Redis 를 써요. Blob 은 연결돼 있어도 Redis 가 있으면 안 써요.
3. Blob 이 다시 열리면(다음 달 또는 요금제 변경) 관리자가 게시판의 「🛡 관리자 → 📦 예전 Blob 기록 가져오기」로 예전 계정·기록을 옮겨요.
- 학습 기록은 각 기기에도 저장돼 있어서, 다시 가입·로그인하면 그 기기의 기록이 그대로 올라가요.

## Vercel에 올리기 (로그인까지)

1. https://vercel.com/new 에서 **Import Git Repository → `connag2/story`** 선택 → 설정은 그대로 두고 **Deploy**.
2. 만든 프로젝트에서 **Storage → Create → Blob** → 접근을 **Private**으로 → 이 프로젝트에 **Connect**.
   (환경 변수 `BLOB_READ_WRITE_TOKEN`이 자동으로 생겨요.)
3. (권장) **Settings → Environment Variables**에 `AUTH_SECRET` = 아무 긴 임의 문자열 추가.
4. **Deployments → Redeploy**. 이제 주소로 들어가 오른쪽 위 「로그인」 → 「회원가입」.

이후로는 `main`에 push할 때마다 자동으로 배포돼요. GitHub Pages처럼 정적 호스팅에서도 열리지만, 그때는 로그인 대신 백업 파일을 써요.

### 로컬에서 실행

```bash
npm install
npm run dev     # http://localhost:3000  (로그인 데이터는 메모리에만 저장)
npm test        # 정답 채점·동기화 병합·로그인 API 점검
```

### 🎙 AI 성우 켜기 (선택)

1. https://platform.openai.com 에서 API 키를 만들어요(쓴 만큼 요금, 문장 하나에 아주 적은 금액).
2. Vercel → Settings → Environment Variables 에 `OPENAI_API_KEY` = 키 → 다시 배포.
3. 영어 본문 해설의 ⚙️ 보기 설정 → 성우에서 골라요. 같은 문장은 Vercel CDN 이 1년 동안 기억해서 두 번째부터는 요금이 안 들어요(Blob 은 안 씀).
- 성우 바꾸기·늘리기: `api/tts.js` 의 `VOICES` 를 고치거나 환경 변수 `TTS_VOICES` 에 `[{"id":"coral","name":"코랄","desc":"밝은","tag":"🎀"}]` 처럼 넣어요. 모델은 `TTS_MODEL`(기본 gpt-4o-mini-tts).
- 다른 회사 음성을 쓰려면 `api/tts.js` 의 `PROVIDERS` 에 함수를 하나 더하면 돼요.
- 아무 글이나 읽히지 못하게 공부 자료(본문 · 해석 · 끊어 읽기 · 단어)에 있는 글만 읽어 줘요.

### 서버 구조

**저장소 사용량 아끼기 (최소화):**
- **동기화 쓰기는 최대 10분에 한 번**: 문제를 풀면 기록은 기기에 먼저 저장되고, 모아서 10분 뒤 · 화면을 떠날 때 · 다음에 열 때 한 번만 서버에 써요. 서버와 같으면 안 써요.
- **새로고침**: 10분 안에 맞췄고 바뀐 게 없으면 서버에 묻지 않아요.
- **포인트**: 맞힌 문제 목록을 학습 기록 파일에 같이 넣어 쓰기 한 번으로 끝. 화면의 🪙 는 서버에 보내기 전에도 바로 올라가요.
- **댓글 · 이모티콘 목록 · 그림**: 로그인 정보 없이 받아서 Vercel CDN 이 기억(댓글 30초 · 목록 1분 · 그림 1년) → 여러 명이 봐도 저장소는 거의 안 읽어요. 내 글 · 👍 · 가진 것 표시는 브라우저가 계산.
- **댓글 칸은 화면에 보일 때만** 불러오고, 새 글 확인은 1분마다(CDN 이 대신 답함).
- **계정 확인**: 내 기록 읽기·쓰기, 포인트 쓰기, 계정 바꾸기만 계정 파일을 확인하고(2분 기억), 나머지는 서명된 토큰만 봐요.
- 측정: `STORE_LOG=1 npm run dev` 로 저장소 읽기·쓰기를 한 줄씩 볼 수 있어요.

## 새 과목 추가하기

1. `data/과목.js` 파일을 만들고 `STORY.addSubject({...})`를 호출합니다 (`data/reading.js` 참고).
2. `index.html` 아래쪽에 `<script defer src="data/과목.js"></script>` 한 줄을 추가합니다.
3. 그림이 필요하면 `assets/<과목 id>/` 폴더에 넣고 `img: ["파일.png"]`로 지정합니다.

### 문제 데이터 형식

```js
STORY.addSubject({
  id: "science", name: "과학", icon: "🔬", color: "#3a8fb7", desc: "설명",
  exam: { count: "선다형 20문제", range: ["1단원 (p.10-30)"] }, // 있으면 '시험 과목'에 표시
  units: [{
    id: "1", title: "단원 이름", sub: "교과서 쪽수",
    groups: [{
      stars: 1, src: "출처", q: "공통 발문 ($수식$ 가능)", img: ["그림.png"],
      items: [
        // [번호, 문제, 정답(표시용), 인정하는 답(문자열·배열, null이면 스스로 채점), 옵션]
        ["(1)", "$1+1$", "$2$", "2"],
        ["(2)", "물의 화학식은?", "H₂O", "H2O", { type: "choice", choices: ["H2O", "CO2"] }],
        ["(3)", "광합성을 설명하시오.", "모범 답안…", null],
      ],
    }],
  }],
});
```

옵션: `type`(`input` · `choice` · `multi` · `self`), `choices`, `shuffle`(보기 섞기), `any`(답 순서 무관), `explain`(해설), `img`.
