# 스토리 공부방 📚

과목별·단원별로 문제를 풀고 바로 채점하는 공부용 웹앱입니다. 빌드 없이 `index.html`만 열면 돼요.

디자인과 흐름(과목 칩, 타일 메뉴, 진행 점이 있는 단원 카드, 오답노트)은 `공부/`의 **고2 영어 공부장**을 따랐고, 영어Ⅱ는 그 앱을 그대로 엽니다.

## 들어 있는 과목 (2학년 2학기 1차 시험 기준)

| 과목 | 내용 | 문제 수 |
|---|---|---|
| 독서와 작문 | 특성과 태도 · 사실적·추론적 읽기 · 평가하며 읽기 (개념 + 연습 지문) | 33 |
| 미적분Ⅰ | 2026 미적분Ⅰ 복습평가 1~11 (7-1 포함), 정답 자동 채점 | 230 |
| 영어Ⅱ | `공부/고2 영어 공부장.html`로 연결 (비상 1·2과, 2025·2026 9월 모의고사) | 공부장 참고 |
| 프로그래밍 | 파이썬 · 개요 · 변수와 연산 · 조건문과 반복문 · 함수 | 46 |
| 국어 기본기 | 음운 변동 · 품사 · 한자 성어 · 문학 표현법 (시험범위 외 보충) | 52 |

## 기능

- 답을 입력하면 바로 채점합니다. `1/4`, `0.25`, `루트6`, `무한대` 처럼 다르게 써도 맞게 처리해요.
- 서술형 문제는 정답을 보고 스스로 ⭕/❌를 채점합니다.
- 틀린 문제는 **오답노트**에 모이고, "틀린 문제만 보기"로 다시 풀 수 있어요.
- 진도는 브라우저(localStorage)에 저장됩니다.
- 수식은 KaTeX로 표시하며 `vendor/katex`에 들어 있어서 인터넷이 없어도 동작합니다.

## 실행

- 그냥 `index.html`을 브라우저로 열거나,
- `python3 -m http.server` 실행 후 http://localhost:8000 접속,
- GitHub Pages: 저장소 Settings → Pages → Branch 선택 후 저장.

## 새 과목 추가하기

1. `data/과목.js` 파일을 만들고 `STORY.addSubject({...})`를 호출합니다 (`data/reading.js` 참고).
2. `index.html` 아래쪽에 `<script defer src="data/과목.js"></script>` 한 줄을 추가합니다.
3. 그림이 필요하면 `assets/<과목 id>/` 폴더에 넣고 `img: ["파일.png"]`로 지정합니다.

### 문제 데이터 형식

```js
STORY.addSubject({
  id: "science", name: "과학", icon: "🔬", color: "#3a8fb7", desc: "설명",
  exam: { count: "선다형 20문제", range: ["1단원 (p.10-30)"] }, // 있으면 '시험 과목'에 표시
  units: [{
    id: "1", title: "단원 이름", sub: "교과서 쪽수",
    groups: [{
      stars: 1, src: "출처", q: "공통 발문 ($수식$ 가능)", img: ["그림.png"],
      items: [
        // [번호, 문제, 정답(표시용), 인정하는 답(문자열·배열, null이면 스스로 채점), 옵션]
        ["(1)", "$1+1$", "$2$", "2"],
        ["(2)", "물의 화학식은?", "H₂O", "H2O", { type: "choice", choices: ["H2O", "CO2"] }],
        ["(3)", "광합성을 설명하시오.", "모범 답안…", null],
      ],
    }],
  }],
});
```

옵션: `type`(`input` · `choice` · `multi` · `self`), `choices`, `shuffle`(보기 섞기), `any`(답 순서 무관), `explain`(해설), `img`.
